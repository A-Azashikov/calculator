# Calculator

Данный репозиторий представляет мое идение системы расчета связанных показателей эффективности. Этот код не является production-ready системой, это лишь эксперимент для проверки гипотезы.

## Контекст

Система в первую очередь предназначена для работы с данными IoT датчиков которые сохраняются в витрину данных.
Система реализована в виде нескольких конвейеров (source, calculation, aggregation).

Source - собирает параметры расчетов и запрашивает данные из витрины с помощью батчинга

Calculation - на основе данных из источников и расчитанных данных проводит расчет дерева показателей эффективности

Aggregation - собирает результаты расчетов во временные окна по заданным параметрам агрегации

## Структура
